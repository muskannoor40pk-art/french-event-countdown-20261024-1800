## Overview
This project provides a professional, lightweight, and responsive landing page template tailored for product launches. Designed with the West & Central African and European markets in mind, it ensures fast loading times even in regions with varying internet connectivity. It features a live countdown timer, a structured agenda section, and a newsletter subscription form to capture leads before your event goes live.

## Features
*   **Live Countdown Timer:** Real-time synchronization to ensure your audience stays updated.
*   **Responsive Design:** Built with Flexbox and Grid to look perfect on mobile, tablet, and desktop.
*   **Agenda Section:** Clearly display your event timeline and key milestones.
*   **Lead Capture:** Integrated subscription form for email marketing.
*   **Zero-Dependency:** Pure Vanilla JavaScript for maximum performance and security.
